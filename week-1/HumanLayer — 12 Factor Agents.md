## HumanLayer – 12 Factor Agents

**Resource:** 12 Factor Agents
**Organization:** HumanLayer

### 5 Most Relevant Factors for Our Team

**1. Own your context window**

AI needs the right information to complete a task properly. If we give too much unrelated information, the AI may get confused.

**How we can implement it:**
We should provide only the relevant project information, requirements, files, and instructions to the AI agent for each task.

---

**2. Make your agent a good librarian**

The AI should be able to find the information it needs instead of depending on someone to provide everything manually.

**How we can implement it:**
Our team should maintain organized project documents and a company brain so that agents can easily find important project information.

---

**3. Small, focused agents**

An agent should have a clear responsibility instead of trying to do everything.

**How we can implement it:**
We can create separate agents for tasks such as coding, code review, testing, or documentation, with each agent having a specific purpose.

---

**4. Give agents control over their work**

Agents should be able to perform the steps required for their assigned task instead of only generating suggestions.

**How we can implement it:**
When appropriate, coding agents can work with project files and development tools to complete their assigned task, while humans still review the final result.

---

**5. Humans should remain in control**

AI agents can make mistakes, so important decisions should not be made without human involvement.

**How we can implement it:**
Every important AI-generated change should be reviewed by a team member before it is merged or accepted.

### Final Team Rules

From these factors, our Team OS should follow these rules:

1. Give agents only the context they need.
2. Keep project knowledge organized and easy to find.
3. Give each agent a clear and focused responsibility.
4. Allow agents to complete useful work within their assigned scope.
5. Keep humans responsible for reviewing and approving important work.
