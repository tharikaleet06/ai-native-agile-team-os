# ai-native-agile-team-os

The **AI-Native Agile Team OS** is a reusable framework designed to help a small software team work effectively with AI agents. It defines how humans and AI can collaborate throughout the software development lifecycle while keeping the development process organized, clear, and reviewable.

The project focuses on building a practical **team operating system**, rather than simply using AI tools individually. It provides a structured approach for planning work, managing project knowledge, assigning tasks to AI agents, reviewing AI-generated work, testing outputs, documenting decisions, and learning from mistakes.

The team follows an **Agile-based workflow** where work is planned in small iterations and progress is regularly reviewed. AI agents can support different activities such as coding, code review, testing, and documentation, while humans remain responsible for important decisions, reviews, and final approval.

The project also includes a **company brain** to maintain important project information, decisions, architecture details, and context. This helps both team members and AI agents access consistent and relevant information while working on the project.

Another important part of the system is the **evaluation and learning loop**. AI-generated outputs are reviewed for quality, errors are tracked, and feedback is used to improve future workflows. This helps the team understand what works well and where AI assistance needs improvement.

The project is developed by a **5-member team**, with each member responsible for a specific area:

- **Product / Sprint Ops Engineer** – planning, coordination, and Agile processes
- **Company Brain / Knowledge Engineer** – project knowledge and context
- **Agent Workflow Engineer** – AI coding, review, and QA workflows
- **Engineering Systems Engineer** – Git, GitHub, code review, and CI/CD practices
- **Evaluation / Learning Loop Engineer** – AI output evaluation and continuous improvement

The overall goal is to create a **practical and reusable starter kit for an AI-native software team** that can be applied to future software projects and demonstrated through a mock sprint.
