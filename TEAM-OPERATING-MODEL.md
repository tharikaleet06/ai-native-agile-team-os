# AI-Native Team Operating Model

## 1. Purpose

The purpose of this operating model is to define how our 5-person team will work together while using AI agents during software development.

We want to use AI to support activities such as planning, coding, research, testing, code review, documentation, and evaluation.

AI will help the team work faster, but humans will remain responsible for understanding the work, reviewing AI output, and making final decisions.

## 3. How Humans and AI Work Together

Our basic working process is:

**Human defines the task → AI works on the task → Human reviews the result → Team improves the work**

AI can support the team with:

* Coding
* Research
* Testing
* Code review
* Documentation
* Problem solving
* Repetitive tasks

Humans will provide direction and context and will review the results before important work is accepted.

---

## 4. AI-Native Team Principles

Based on our Week 1 learning, we will follow these principles:

### Keep AI workflows simple

We will start with simple workflows and add complexity only when it is needed.

### Give clear instructions

AI agents should receive a clear task and expected output.

### Provide relevant context

Agents should receive the information they need to understand the task and project.

### Give agents focused responsibilities

Different agents can have different responsibilities instead of one agent trying to do everything.

### Keep humans involved

AI-generated work should be reviewed by a human before important changes are accepted.

### Learn from mistakes

When AI produces errors or unexpected results, we should identify the problem and improve the workflow.

## 5. Basic Team Collaboration

For each task, the team should understand:

* What needs to be done
* Who is responsible
* What the expected output is
* Current progress
* Any blockers
* What needs to happen next

Team members should share important updates and learnings with the rest of the team.

The Product / Sprint Ops Engineer will help coordinate the team's overall progress.

---

## 6. Human Responsibilities

Humans are responsible for:

* Understanding requirements
* Planning the work
* Giving AI clear instructions
* Providing relevant context
* Reviewing AI-generated work
* Checking quality
* Making final decisions
* Improving the team's workflow

AI should not be treated as the final authority.

## 9. Evaluation and Feedback

AI output should be checked before it is accepted.

The team should look for:

* Hallucinations
* Coding errors
* Missing requirements
* Unexpected results
* Areas for improvement

The Evaluation / Learning Loop Engineer will help track these issues and use the feedback to improve future AI workflows.
